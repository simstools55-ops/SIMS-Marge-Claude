# SIMS Merge

SIMS Editorial Platformにおいて、複数記事のカニバリ・重複・役割競合を安全に整理する専門製品です。

- Product Version: 1.0.0-RC1
- Shared Version: 3.3.0
- Platform Compatibility: 1.x
- Repository Type: Product

## 責務

- カニバリ信頼度の評価
- Primary Article候補の根拠付き選定
- Preservation Map / Query Mapping / Merge Planの生成
- Redirect・noindex・削除候補の提示（自動実行は禁止）
- Writer / Creatorへの後続Referral候補をSBMへ返す

## 非対象

CMSへの直接公開、記事削除、301設定、noindex設定、Case状態変更は行いません。
